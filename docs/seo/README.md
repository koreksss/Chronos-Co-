## Пояснение по Pull Request
К сожалению, у меня не получилось корректно создать Pull Request. Ветки `frontend` и `backend` имеют независимые истории коммитов, из-за чего их сравнение на GitHub работает не так, как я ожидала.
Я попробовала создать отдельную ветку `seo-work` и перенести в неё коммиты с SEO-изменениями, однако содержимое этой ветки совпало с `frontend`, поэтому полезных различий для Pull Request не осталось.
Чтобы не рисковать работоспособностью проекта, я решила не объединять независимые ветки. Все выполненные изменения сохранены в `frontend`, а история моей работы доступна на GitHub.
